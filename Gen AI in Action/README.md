# Generative AI in Action — My Learnings & Notes

This repository captures **my personal understanding and implementation insights** from the book  
**"Generative AI in Action" (Anaconda Sponsored | Manning Publications)**.  

It’s not a reproduction of the book, but rather a **conceptual and practical interpretation** of key topics — summarized, coded, and explained in my own way.  
I created this as part of my learning journey to deepen my understanding of Generative AI, LLMs, and their real-world applications.

---

## PART 1 — Foundations of Generative AI

### 1️⃣ Introduction to Generative AI
Understanding what Generative AI is, its capabilities, use cases, limitations, and how it differs from traditional AI.

### 2️⃣ Introduction to Large Language Models (LLMs)
Exploring transformer architectures, model types, tokenization, embeddings, and emergent behaviors in LLMs.

### 3️⃣ Working through an API: Generating Text
Hands-on overview of text generation using APIs — completions, chat-based interfaces, token control, and advanced configurations.

### 4️⃣ From Pixels to Pictures: Generating Images
Learning about diffusion models, GANs, and multimodal models — along with image generation and enhancement using Stable Diffusion and other APIs.

### 5️⃣ What Else Can AI Generate?
Extending GenAI to code, music, video, and other creative domains with tools like GitHub Copilot, Code Llama, and more.

---

## PART 2 — Advanced Techniques and Applications

### 6️⃣ Guide to Prompt Engineering
Key principles, strategies, and best practices for crafting effective prompts across text and image generation.

### 7️⃣ Retrieval-Augmented Generation (RAG): The Secret Weapon
Deep dive into RAG pipelines — integrating vector databases, chunking data, and building retrieval-based GenAI applications.

### 8️⃣ Chatting with Your Data
Developing custom chatbots that leverage enterprise data with RAG and vector databases like Redis or Pinecone.

### 9️⃣ Tailoring Models with Model Adaptation and Fine-Tuning
Understanding fine-tuning workflows, LoRA techniques, RLHF, and model customization for specific tasks or domains.

---

## PART 3 — Deployment and Ethical Considerations

### 🔟 Application Architecture for Generative AI Apps
Designing scalable GenAI systems — understanding the orchestration, grounding, and model layers in production environments.

### 11️⃣ Scaling Up: Best Practices for Production Deployment
Exploring LLMOps, deployment strategies, observability, security, and scalability in GenAI pipelines.

### 12️⃣ Evaluations and Benchmarks
Learning about traditional and LLM-based evaluation metrics like BLEU, ROUGE, BERTScore, and G-Eval for GenAI performance assessment.

### 13️⃣ Guide to Ethical GenAI
Addressing bias, safety, transparency, and responsible AI development — with frameworks for red-teaming and content moderation.
